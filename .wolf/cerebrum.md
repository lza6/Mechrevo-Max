# Cerebrum（跨会话学习）

## User Preferences

- 用户希望功能丰富、信息透明、参考 HWiNFO 与官方控制台的分区仪表，但不要伪造“真实生效值”。
- 自主完成能完成的工作，少要求用户逐步点头；真实闭环与证据优先。
- 真机 UI 自动化与压力测试禁止；可用独立浏览器 + mock IPC 验证前端。
- 回复与文档使用简体中文，代码/命令保留英文。

## Key Learnings

- EC 与系统信息是不同依赖：外部查询必须超时且不得持 EC 锁；EC 不可用时免驱数据仍应可读。
- WMI 类存在不等于硬件存在；全零电池对象不能渲染为 0% 电量。
- `BatteryTemperature.Temperature` 是十分之一开尔文，需 `/10.0 - 273.15`，不是 `/10`。
- `[N/A]` 与字段缺失是“未知”，不是 0；电池百分比和内存字段用 Option。
- `read_block` 地址必须拒绝环绕；`0x0FFF` 之后不能读。
- `cargo test` 的 rustdoc 可能来自失效的 Chocolatey shim；显式使用 rustup 工具链内 `rustdoc.exe`。
- 前端首屏 mock 必须先提供状态；否则 EC 会停在“检测中”。这是脚手架问题，不是产品结论。
- 真机 `0x751` 当前实测为 `0x00`（2026-10-25 健康检查）；此前 `0x40` 的强冷开状态不能继续当现在的事实。

## Do-Not-Repeat

- 2026-10-25：不要把外部采样放在 EC 互斥里，即使位于 `open_ec()` 之前。
- 2026-10-25：不要把 `[N/A]`、无电池、未知内存转换为 0。
- 2026-10-25：不要把电池 WMI 温度除以 10 就当 °C。
- 2026-10-25：不要靠 `cargo test --lib` 代替包含 doctest 的完整验证，也不要因 shim 失败跳过测试。
- 2026-10-25：不要在独立 reviewer 给出 Approve 前宣称审查通过。
- 2026-10-25：不要为清理计划而删除仍有未闭环项的路线图。
- 2026-10-25：不要把旧版卡片 UI 的断言数量当作当前分区界面的覆盖证据。

## Decision Log

- 保持不实现 Tauri 自动更新：离线与签名供应链风险；保留手动下载。
- 风扇曲线当前只读；不与官方 UserFanTables 逐点核对前不写。
- 系统实际生效 PL（MSR）不在用户态硬猜，不宣称 EC 默认值就是实际生效值。
